  • Thesis

    Post-quantum blind signatures from MPC

    Blind signatures let someone sign a message without seeing it - but existing quantum-resistant versions come with huge keys and signatures. My thesis computes a SPHINCS+ signature inside two-party secure multi-party computation instead. The result: a 64-byte public key and ~50 KB signatures at 256-bit security, signing in about 38 seconds in plain Python - with clear headroom once it moves to C.

    Cryptography · SPHINCS+ · MPC · Python (MPyC)
